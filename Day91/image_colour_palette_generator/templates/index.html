How it works

  1. The app saves the uploaded image temporarily in the project folder.
  2. Pillow opens and resizes the image so the process stays fast.
  3. NumPy turns the image into an array of RGB pixel values.
  4. Similar colours are grouped together so the palette is useful instead of noisy.
  5. The 10 most frequent grouped colours are displayed with HEX codes.
