API documentation

The website also has REST-style JSON endpoints.

Method Endpoint Purpose
GET/api/cafesReturns all cafes.
GET/api/cafes/<id>Returns one cafe by id.
GET/api/randomReturns one random cafe.
GET/api/search?location=PeckhamSearches cafes by location.
POST/api/cafesAdds a cafe using JSON or form data.
DELETE/api/cafes/<id>Deletes one cafe.

Example JSON for adding a cafe

{
  "name": "Example Cafe",
  "map_url": "https://maps.google.com/example",
  "img_url": "https://example.com/photo.jpg",
  "location": "London",
  "has_wifi": true,
  "has_sockets": true,
  "has_toilet": true,
  "can_take_calls": false,
  "seats": "20-30",
  "coffee_price": "£2.80"
